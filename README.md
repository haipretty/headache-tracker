# 日常头疼记录本（微信小程序）

> 已上线 ✅ | 备案号：粤ICP备2026071573号

## 项目简介

一款轻量化微信小程序，用于记录偏头痛发作详情、追踪发作规律，方便自查与就医参考。
基于医学界公认最有效的偏头痛管理方式——「记录 + 避免诱因」而设计。

**产品理念：零门槛**——无登录、无授权、无账号体系，打开即可使用。

## 技术栈

- 微信小程序原生开发（WXML / WXSS / JS）
- 微信云开发（云数据库，后按需求变更评估迁移至本地存储，10MB 容量约可存 5 万条记录）

## 功能特性

- ✅ **新增/编辑记录**：同一页面兼容两种场景，编辑模式自动回填
- ✅ **结构化录入**：开始/结束时间、疼痛等级（1-10）、疼痛部位、诱发原因、伴随症状、用药记录、备注
- ✅ **多维标签多选**：部位（太阳穴/全头/后脑勺等）、诱因（熬夜/压力/生理期等）、症状（畏光/恶心等）
- ✅ **记录管理**：按发作时间倒序展示，支持编辑与单条删除
- ✅ **空状态引导**：无记录时引导创建第一条
- ✅ **云端存储**：数据永久保存，单设备独立使用

## 数据库设计（headache_record 集合）

| 字段 | 说明 |
| --- | --- |
| startTime / endTime | 发作起止时间（endTime 可空，适配未结束场景） |
| painLevel | 疼痛等级 1-10 |
| position / induce / symptom | 部位 / 诱因 / 症状（数组，多选） |
| drugName / drugTime | 用药名称与时间（可空） |
| remark | 备注文本 |

## 产品决策记录

- **为什么无登录？** 纯工具定位，降低使用门槛，患者发作时能以最快速度完成记录
- **云存储 → 本地存储的变更评估**：测算了单条记录约 130-380 字节，10MB 本地存储足够使用 13 年以上，据此完成存储方案迁移决策
